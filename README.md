# منصة سوق المصريين — النسخة الأولية

هذه نسخة واجهة تجريبية Mobile-first مبنية بـ HTML/CSS/JavaScript، تستخدم لوجو الشركة المرفق.

## تشغيلها
- فك ضغط الملف.
- افتح `index.html` في متصفح الهاتف أو الكمبيوتر.
- جرّب إضافة إعلان مجاني وطلب إعلان مدفوع، ثم افتح "لوحة الإدارة التجريبية".

## مهم جدًا
هذه ليست منصة إنتاج جاهزة:
- لا يوجد خادم أو قاعدة بيانات مشتركة.
- لا يوجد تسجيل دخول حقيقي أو صلاحيات آمنة.
- البيانات تحفظ في LocalStorage على نفس المتصفح والجهاز.
- لا يوجد دفع إلكتروني فعلي.
- لوحة الإدارة التجريبية غير محمية؛ لا تضع بيانات حقيقية أو كلمات مرور فيها.

## الخطوة التالية
اختيار الاستضافة وقاعدة البيانات والخادم، ثم تحويل النماذج إلى API آمن مع حسابات التجار وصلاحيات الإدارة ومراجعة الإعلانات وتكامل الدفع بعد اعتماده.
